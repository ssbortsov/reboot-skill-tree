# Карта навыков digital-дизайнера REBOOT

Интерактивное дерево навыков и грейдов для дизайнеров студии: от джуна до дизайн-директора,
с двумя направлениями — классический веб и игры с геймификацией.

## Что внутри

- `index.html` — основная версия: база, деревья-колонки, ярусы грейдов, кэпстоуны.
- `v1/index.html` — ранняя радиальная версия, оставлена для истории.
- `skills.json` — та же структура в виде данных: грейды, шкала уровней, ветки, навыки и требования.

Обе страницы самодостаточны: никакой сборки и зависимостей, только шрифты с Google Fonts.
Открываются двойным кликом или с любого статического хостинга.

## Как устроено

- **База** — 9 навыков, без которых ветки не открываются. Грейд джуна равен базе на уровне 1.
- **Ветки** — 9 общих плюс две специализации: «Классический веб» и «Игры и геймификация».
- **Грейды** — джун, мидл, сеньор, арт-директор, дизайн-директор. Для каждого навыка задан
  требуемый уровень 0–5 на каждом грейде.
- **Треки** — с мидла в грейд идёт только выбранная специализация. Дизайн-директор совмещает обе.
- **Кэпстоуны** — по одному внизу каждой ветки, появляются только у дизайн-директора.

## Шкала уровней

| Уровень | Что значит |
|---|---|
| 0 | не требуется |
| 1 | знаком, делает под присмотром |
| 2 | делает сам типовые задачи |
| 3 | делает сам сложное и отвечает за результат |
| 4 | задаёт стандарт и учит других |
| 5 | развивает практику, влияет за пределами студии |

## Управление

- Клик по узлу — карточка навыка: требования по грейдам, состав, «мой уровень».
- Перетаскивание навыка — перенос в другую ветку или на другое место.
- Заголовки и описания в панели редактируются кликом.
- «Мой уровень» — режим самооценки с подсчётом разрыва до выбранного грейда.
- «Скопировать структуру» — выгрузка текущей карты в JSON.

Правки, оценки и перестановки хранятся в localStorage браузера и не попадают в репозиторий.
Чтобы зафиксировать изменения, скопируйте структуру и обновите `skills.json` и данные в `index.html`.
